# Java Chatbot

This is a small chatbot with a window where you can type a question. It can answer a few questions about Java and the CodeAlpha project tasks. Press **Enter** or click **Send**. The buttons at the bottom let you try some topics.

The chatbot looks for words in your message and picks a matching answer. It only knows the topics covered in the program, so it may not understand every question.

## Run

Open a terminal in this folder and enter:

```bash
javac -d out src/Main.java
java -cp out Main
```
