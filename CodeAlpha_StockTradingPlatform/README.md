# Stock Trading Platform

This program is a simple stock trading game. It starts you with ₦1,000,000 and lets you check prices, buy shares, sell shares, and view your portfolio.

The prices are examples and do not change. Your cash and shares reset when you close the program.

## Run

Open a terminal in this folder and enter:

```bash
javac -d out src/Main.java
java -cp out Main
```
